# decision-log

`DECISIONS.md` に以下のフォーマットで1エントリを追記する。

```
## YYYY-MM-DD: <決定の見出し>
- 背景: なぜこの決定が必要だったか（1文）
- 決定: 何を決めたか（1文）
- 理由: なぜこの選択肢か。代替案があれば併記
- 影響ファイル: 変更したファイル一覧
```

- 1エントリは短く。長い議論は書かない。
- 同じ問題を再実装する前には、必ず既存の `DECISIONS.md` を検索してから着手する。
- 些細な変更（typo修正等）には使わない。「非自明な判断」だけ記録する。
