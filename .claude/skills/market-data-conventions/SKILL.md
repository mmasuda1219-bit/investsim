# market-data-conventions

## マーケットプロバイダ（優先順）
1. Yahoo Finance Direct（メイン）
2. Twelve Data
3. J-Quants
4. Mock（開発中の一時的フォールバックのみ。本番の恒久経路には使わない）

## 実データ必須ルール（`COMPANY.md` 原則9）
- 過去データ・現在の株価・出来高・ニュースなどは、必ず実在のAPIから取得したデータを使う。
- 取得に失敗した場合の扱い:
  - 開発中: Mockプロバイダへの一時フォールバックは可（ただしUI上で「モックデータ表示中」と明示する）
  - 本番相当のコードパス: 単にモックへ無言フォールバックすることを禁止。エラーとして扱うか、リトライ/別プロバイダへのフェイルオーバーを行う。

## 通貨・資金の扱い（`COMPANY.md` 原則10）
- 通貨単位は実際の単位（円・ドル等）をそのまま使う。
- ポートフォリオの資金はすべて仮想。実際の銀行口座・証券口座・決済API（送金、入出金等）と連携するコードは書かない。

## レート制限・実装時の注意
- 各プロバイダのレート制限は個別に調査する（researcherに委譲可）。
- 複数プロバイダを跨ぐ場合は、フェイルオーバー順序を `lib/` 内のプロバイダ抽象化レイヤーで統一する。
